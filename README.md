# Mohamed-App-Factory

A reusable application factory: build shared business capabilities once and
reuse them across vertical applications (Sales, Property & Rental, and future
apps).

## Repository layout

- `docs/` — architecture decisions (ADRs), assessments, and agent skills.
- `prototypes/` — working prototypes used to validate requirements and
  decisions. **Not production code.** See
  [prototypes/README.md](prototypes/README.md).
- `apps/`, `modules/`, `platform/` — the production factory itself
  (per ADR-0001). Created in Milestone 1 (ADR-0003).

## Documentation

- [Architecture assessment](docs/architecture-assessment.md) — initial
  architectural consultation.
- [Decisions](docs/DECISIONS.md) — index of Architecture Decision Records.
